# AI_Project

Sistema de recomendación utilizando Inteligencia Artificial y GitHub Copilot.

## Descripción

Este proyecto corresponde a una actividad práctica sobre tendencias de Inteligencia Artificial utilizando GitHub Copilot.

## Herramientas utilizadas

- GitHub
- Visual Studio Code
- Git
- GitHub Copilot
- Python

## Sistema de recomendación

Se desarrolló un sistema sencillo de recomendación basado en las preferencias del usuario y categorías de productos.

El programa permite ingresar preferencias y obtener productos relacionados con dichas categorías.

## Desarrollo

1. Creación del repositorio en GitHub.
2. Clonación del repositorio en Visual Studio Code.
3. Creación del archivo `recommendation-system.py`.
4. Utilización de GitHub Copilot para apoyar la generación del código.
5. Prueba del sistema de recomendación.
6. Registro de los cambios mediante Git.
7. Publicación del proyecto en GitHub.

## Resultado

El sistema permite generar recomendaciones de productos de acuerdo con las preferencias ingresadas por el usuario.
